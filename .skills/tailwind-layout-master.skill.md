# Tailwind Layout Master Skill

## Overview
Expertise in building responsive, themeable, and high-performance UI layouts using Tailwind CSS (v4) and CSS variables.

## Capabilities
- Build dynamic theme engines (Dark/Light/Cyberpunk).
- Implement responsive game grids and sidebar navigation.
- Use CSS variables for design system tokens (colors, spacing, typography).

## Rules
- USE semantic color names (e.g., `--color-primary`) instead of hardcoded hex.
- ENSURE mobile-first responsiveness.
- AVOID `!important` unless absolutely necessary for external iframe overrides.
- VALIDATE layout performance using Chrome DevTools.
