# Audit Specialist Skill

## Overview
Specialized in performing comprehensive project-wide audits across performance, security, UI/UX, and data consistency to ensure a premium, bug-free experience.

## Capabilities
- **Performance Audit**: Use Lighthouse and browser-tracing to identify latency and asset optimization opportunities.
- **Redundancy Audit**: Scan for duplicate CSS/JS, unused library hooks, and redundant logic across the infrastructure.
- **Consistency Audit**: Standardize game titles, metadata, and UI patterns across the entire 15k+ game library.
- **UI/UX Audit**: Validate visual consistency, accessibility, and intuitive navigation flows.
- **Security Audit**: Perform regular Row Level Security (RLS) checks and secret leak detection.

## Rules
- **COMPREHENSIVE**: Audits must cover all layers: code, database, and infrastructure.
- **ACTIONABLE**: Every audit finding must be converted into a specific, trackable task in the roadmap.
- **REGULAR**: Perform a mini-audit after every major feature deployment.
- **ZERO TOLERANCE**: High-risk security or performance blockers must be addressed before proceeding with new features.
