# UI Validator Skill

## Overview
Ensures visual consistency, accessibility, and functional correctness of the user interface.

## Capabilities
- Perform visual regression tests using browser screenshots.
- Validate responsive behavior across Mobile, Tablet, and Desktop viewports.
- Check accessibility (A11y) using Lighthouse snapshots.

## Rules
- VALIDATE every new component before merging.
- ENSURE interactive elements have pointer cursors.
- CHECK for console errors and hydration mismatches.
- VERIFY that theme colors (Dark/Light) are applied consistently.
