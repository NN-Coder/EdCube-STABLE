# Lighthouse Performance Agent Skill

## Overview
Automated performance auditing and optimization for asset delivery and rendering.

## Capabilities
- Run Lighthouse audits via `chrome-devtools-mcp`.
- Identify unoptimized images, blocking scripts, and layout shifts (CLS).
- Recommend lazy loading and asset minification strategies.

## Rules
- AIM for 90+ score in Performance and Accessibility.
- PRIORITIZE fixing Core Web Vitals (LCP, INP, CLS).
- AUTOMATE audits after major UI changes.
- REDUCE TBT (Total Blocking Time) by offloading logic to Workers.
