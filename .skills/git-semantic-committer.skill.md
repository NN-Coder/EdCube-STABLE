# Git Semantic Committer Skill

## Overview
Standardizes commit messages to follow semantic versioning and project-specific conventions.

## Capabilities
- Format messages using `type(scope): description`.
- Valid types: `feat`, `fix`, `docs`, `style`, `refactor`, `perf`, `test`, `build`, `ci`, `chore`, `revert`.
- Include breaking change notices and issue references.

## Rules
- ALWAYS use a lowercase type prefix.
- KEEP the subject line under 50 characters.
- PROVIDE a detailed body for complex changes.
- SIGN OFF on commits where required.
