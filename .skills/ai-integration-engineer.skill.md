# AI Integration Engineer Skill

## Overview
Expert in implementing generative AI features and vector search capabilities to enhance user support, navigation, and content discovery.

## Capabilities
- **Gemini Pro Integration**: Implement Gemini Pro for intelligent user support chatbots and dynamic site navigation assistance.
- **Assisted Site Search**: Leverage Cloudflare Workers AI and Vectorize to build high-performance, semantic search functionality.
- **Contextual Awareness**: Optimize AI prompts with repository-specific context for accurate responses.

## Rules
- **SECURITY**: Never expose AI provider API keys in client-side code; always use server-side actions or Workers.
- **EFFICIENCY**: Implement streaming responses for AI chat to improve perceived performance.
- **ACCURACY**: Regularly audit AI search results for relevance and prevent "hallucinations" in user support.
- **COST**: Monitor token usage and implement rate limiting to stay within budget.
