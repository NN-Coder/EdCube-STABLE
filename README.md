# EdCube

The goal of EdCube is to provide people with a quick and easy way to access a large library of fun games to play at home or with friends. EdCube aims to be completely ad-free to give users the best possible experience. Please note that there may still be ads in specific games, but these are set by those game develops, not EdCube, and we make no profit from them.

If you enjoy using any of EdCube's services, please consider giving this repository a like, follow, and/or fork. Following us on any of our social media platform accounts also greatly help us. The accounts can be found in the footer section of our EdCube's main game page.
